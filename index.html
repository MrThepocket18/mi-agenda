      Apple Calendar

      Conecta la agenda con GitHub una sola vez. Tus tareas se guardan en un archivo privado de tu cuenta y Apple Calendar se actualiza solo.
      1. Abre este enlace de GitHub (inicia sesión si te lo pide).
      2. En «Expiration» elige No expiration, deja marcada solo la casilla gist y pulsa Generate token.
      3. Copia el código que empieza por ghp_ y pégalo aquí:
      Suscribe tu calendario a esta dirección una sola vez:
      iPhone/iPad: Ajustes → Apps → Calendario → Cuentas de calendario → Añadir cuenta → Otra → Añadir calendario suscrito → pega la dirección → Siguiente → Guardar.
      Mac: app Calendario → Archivo → Nueva suscripción a calendario… → pega la dirección → en «Actualización automática» elige Cada 5 minutos.
      Las tareas aparecen como eventos de todo el día; las hechas, con ✓ delante. Los cambios tardan unos minutos en llegar, según la frecuencia de actualización del calendario.
      ¿Desconectar este dispositivo? Tus tareas siguen guardadas en GitHub.
